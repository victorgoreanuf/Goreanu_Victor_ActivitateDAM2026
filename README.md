# Goreanu_Victor_ActivitateDAM2026

Repository pentru laboratoarele și codul sursă realizate de **Goreanu Victor** la disciplina **Dispozitive și Aplicații Mobile**, în semestrul din 2026.

## Organizare

Fiecare proiect Android va avea propriul folder în acest repository, de exemplu `Laborator01/`, `Laborator02/` etc. Alternativ, laboratoarele pot fi organizate ca module ale unui singur proiect Android.

Momentan, repository-ul este pregătit pentru adăugarea primului proiect.

- Toată activitatea se păstrează pe un singur branch: `main`.
- Proiectele noi se adaugă lângă cele existente, fără a le șterge.
- Nu se inițializează repository-uri Git separate în folderele proiectelor.
- Se păstrează codul sursă, resursele, fișierele Gradle și Gradle Wrapper (`gradlew`, `gradlew.bat`, `gradle/wrapper/`).
- Fișierele generate, setările locale și cheile de semnare sunt excluse prin `.gitignore`.

## Lucrul din Android Studio

1. Creează primul proiect într-un subfolder al acestui repository, de exemplu `Laborator01/`.
2. În setările **Version Control → Directory Mappings**, verifică dacă folderul părinte al laboratoarelor este asociat cu **Git**. Versionarea este deja inițializată în acel folder.
3. Lucrează pe `main`, verifică fișierele modificate, apoi folosește **Commit** și **Push**.
4. Pentru proiectele următoare, păstrează aceeași rădăcină Git.

## Ritmul de lucru și predarea

- În fiecare săptămână: commit și push pentru activitatea realizată, cel târziu vineri seara, până la sfârșitul semestrului.
- Repository-ul de pe GitHub trebuie să fie **public** și să se numească `Goreanu_Victor_ActivitateDAM2026`.
- Link-ul repository-ului se predă pe platforma cursului până la **30 octombrie 2026, ora 23:00** (ora României).

După fiecare push, verifică pe GitHub că apar ultimul commit și fișierele lucrate.
